# Preprocessing Workflow

1. Collect raw data and document the source.
2. Preserve original files and create a data inventory.
3. Inspect schema, data types, missingness, categories, and ranges.
4. Standardize names, dates, data types, and measurement units.
5. Detect exact and business-key duplicates and resolve conflicts.
6. Assess missing values and choose a justified treatment.
7. Flag and investigate outliers using plots, statistical rules, and source checks.
8. Filter, join, and aggregate records according to the research question.
9. Create derived features and scale variables only when needed.
10. Validate row counts, keys, units, categories, dates, and joins.
11. Export processed data and update the cleaning log.
12. Use the approved dataset for analysis or modelling.

## Reproducibility essentials
- Preserve raw data unchanged.
- Keep a data dictionary and cleaning log.
- Document assumptions, exclusions, and transformations.
- Version scripts and documents.
- Do not commit credentials or restricted data.
