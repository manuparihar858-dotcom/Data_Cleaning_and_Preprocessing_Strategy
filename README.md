# Week 2. Data Cleaning and Preprocessing Strategy

This repository contains the assignment report for planning data cleaning and preprocessing for a hypothetical agribusiness dataset.

## Contents
- `report/Data_Cleaning_and_Preprocessing_Strategy.docx` contains the detailed strategy document.
- `project_plan/preprocessing_workflow.md` contains the workflow sequence in Markdown.

## Scope
The report describes common data quality issues and proposes methods for missing values, inconsistent formats, duplicates, outliers, unit conversions, filtering, aggregation, and scaling. It also discusses validation, reproducibility, and a hypothetical example.

The dataset is hypothetical. The document does not claim that real data has been collected or cleaned.

## Suggested next steps
Review the strategy against the actual dataset once one is supplied. Adapt allowed ranges, imputation choices, duplicate keys, and scaling methods to the data definitions and research question. Preserve the original source files and record all changes.
